## Scope and Limitations

### Conditional Server Action Review

`src/actions/admin.ts` is a `'use server'` module exporting
`getShiprocketAuth(forceRefresh?)` and `shiprocketFetch(endpoint, options?)`
without wrapper-level authorization. The former delegates to code that returns a
Shiprocket token and a DB account profile containing credential fields; the
latter can issue a caller-selected upstream path. No client call sites or
helper-name references in the current `.next/static` bundle were found, and
Next's installed docs describe dead-code elimination for unused action
references. Therefore public reachability is **NOT VERIFIED**, not confirmed.
Keep as HIGH-priority conditional review until the production action manifest is
checked. If callable, require server-side authorization, constrain routes/verbs,
and return a minimal non-secret shape. No code was changed.

This review did not inspect live Vercel settings, provider dashboards,
production logs, database access policies, secrets history outside tracked Git,
deployed response headers, or third-party contracts. Findings are not a legal
opinion or certification. No production code has been modified.
